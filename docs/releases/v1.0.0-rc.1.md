## novalis v1.0.0-rc.1

Der Release-Kandidat für 1.0. Seit der zweiten Vorabversion: ein Journal,
ein durchgängiger Weg zwischen Notizen und Kanban-Karten, Links und Anhänge,
die beim Verschieben heil bleiben — und die Prüfung auf OneDrive und Google
Drive ist abgeschlossen.

The release candidate for 1.0. Since the second pre-release: a journal, a
continuous path between notes and Kanban cards, links and attachments that
survive a move — and testing on OneDrive and Google Drive is complete.

### Neu / New

- **Journal:** `⌘J` öffnet die heutige Notiz (auch im Menü Gehe zu);
  „Vorheriger Tag" / „Nächster Tag" in der Befehlspalette springen zwischen
  vorhandenen Tagesnotizen; Datum und Uhrzeit einfügen.
- **Kanban:** eine Notiz auf eine Spalte ziehen macht eine Karte; „Notiz
  verknüpfen…" öffnet eine Auswahl; Kontextmenü auf Karten mit „In Spalte
  verschieben"; „Notiz aus Karte anlegen" und „Neue Karte aus Auswahl";
  Kartenbeschreibung als Markdown dargestellt; „Board löschen" (in den
  Papierkorb, verknüpfte Notizen bleiben).
- **Tabs und Editor:** Tabs per Ziehen umsortieren; „Andere Tabs schließen"
  und „Alle Tabs schließen"; „Zeilen sortieren", „Zeilen verbinden",
  „Unsichtbare Zeichen anzeigen".
- **Links und Suche:** `⇧⌘F` übernimmt die Auswahl; `⌘`-Klick auf einen
  `#tag` sucht danach; `⌘P` zeigt zuletzt geöffnete Dateien zuerst und
  springt mit `@` zu Überschriften; fehlende Notizen aus `⌘P` oder aus einem
  unaufgelösten `[[Link]]` anlegen (unaufgelöste Links sind gestrichelt);
  Aufgaben-Kästchen im Lesemodus anklickbar; Web- und Mail-Links öffnen im
  Standardprogramm.
- **Dateien:** eine Datei aus dem Baum in eine Notiz ziehen fügt einen Link
  ein; PDFs als Anhang; Bilder und PDFs aus dem Finder auf einen Ordner
  ziehen kopiert sie hinein; verschobene Notizen behalten ihre relativen
  Links; „Pfad kopieren", „Link zur Notiz kopieren", „Mit Standardprogramm
  öffnen", Rückverweise im Menü Darstellung.
- **macOS:** novalis steht unter „Öffnen mit" für `.md`, `.markdown`,
  `.txt` (ohne Standardprogramm zu werden) und nimmt Dateien vom Dock an;
  `novalis://today` und `novalis://open?path=…`.
- **Kommandozeile:** `novalis journal`, `novalis board new`,
  `search --regex` / `--case-sensitive`, `cat` auf Nicht-Notiz-Dateien;
  Werte dürfen mit `-` beginnen; ein Pfad wie `index.md` an der Wurzel wird
  exakt aufgelöst; Lesebefehle sind auch bei laufender App sofort aktuell.
- **Verlässlichkeit in Cloud-Ordnern:** OneDrive-Konfliktkopien mit
  Leerzeichen im Computernamen werden erkannt; eine reine
  Groß-/Kleinschreibungs-Umbenennung hinterlässt keinen Geistereintrag; ein
  über einen Symlink geöffneter Vault (Google Drive im Spiegelmodus) sieht
  externe Änderungen; einen ladenden Tab schließen bricht das Öffnen ab.

- **Journal:** `⌘J` opens today's note (also in the Go menu); "Previous Day"
  / "Next Day" in the command palette step between existing day notes;
  insert date and time.
- **Kanban:** dropping a note on a column makes a card; "Link Note…" opens a
  picker; a context menu on cards with "Move to Column"; "Create Note from
  Card" and "New Card from Selection"; card descriptions rendered as
  Markdown; "Delete Board" (to the Trash, linked notes untouched).
- **Tabs and editor:** reorder tabs by drag; "Close Other Tabs" and "Close
  All Tabs"; "Sort Lines", "Join Lines", "Show Invisibles".
- **Links and search:** `⇧⌘F` starts from the selection; `⌘`-click on a
  `#tag` searches for it; `⌘P` lists recently opened files first and jumps
  to headings with `@`; create missing notes from `⌘P` or an unresolved
  `[[link]]` (unresolved links are drawn dashed); task boxes clickable in
  the preview; web and mail links open in the default app.
- **Files:** dragging a tree file into a note inserts a link; PDFs as
  attachments; images and PDFs dropped from the Finder on a folder are
  copied there; moved notes keep their relative links; "Copy Path", "Copy
  Link to Note", "Open in Default App", backlinks in the View menu.
- **macOS:** novalis appears under "Open With" for `.md`, `.markdown`,
  `.txt` (without becoming the default app) and takes files dropped on the
  Dock; `novalis://today` and `novalis://open?path=…`.
- **Command line:** `novalis journal`, `novalis board new`,
  `search --regex` / `--case-sensitive`, `cat` on non-note files; values
  may start with `-`; a path such as `index.md` at the root resolves
  exactly; reads are current right away, also while the app runs.
- **Reliability in cloud folders:** OneDrive conflict copies named after a
  computer name with spaces are recognised; a case-only rename leaves no
  phantom entry; a vault opened through a symlink (Google Drive in Mirror
  mode) sees external changes; closing a loading tab cancels the open.

### Bekannt / Known

- **Google Drive legt keine Konfliktkopie an.** Wird dieselbe Notiz auf zwei
  Geräten geändert, behält Drive eine Version und verwirft die andere stumm;
  novalis kann das nicht sehen. Die verworfene Version bleibt im
  Drive-Versionsverlauf. OneDrive: Konfliktkopien werden im Baum markiert;
  auflösen muss man sie von Hand.
- **Papierkorb auf Google Drive:** Gelöschtes landet im Papierkorb von
  Drive, nicht im Papierkorb des Macs; „Zurücklegen" im Finder gibt es
  dafür nicht.
- **Ein Absturz in der ersten Sekunde nach dem Tippen** kann diese Sekunde
  verlieren (gespeichert wird nach 1 s Pause; kein Absturzjournal).
- **OneDrive meldet eine Änderung in mehreren Schritten;** der Baum
  aktualisiert sich dann kurz mehrmals, das Ergebnis stimmt.
- **Einmal ungeklärt (2026-09-17):** eine Nur-Online-Notiz auf Google Drive
  verschwand nach „In den Papierkorb" aus dem Ordner. Der heutige Weg
  verweigert das sichtbar (3 von 3 Läufen); die Ursache ist nicht gefunden.
- Die Kommandozeile ist bis 1.0.0 noch nicht eingefroren; Befehle und
  JSON-Formen können sich bis dahin ändern.
- Unsigniert: siehe „erster Start" unten. Nur Apple Silicon, macOS 14+.

- **Google Drive makes no conflict copy.** When the same note changes on two
  devices, Drive keeps one version and silently drops the other; novalis
  cannot see that happen. The dropped version stays in Drive's version
  history. OneDrive: conflict copies are marked in the tree; resolving them
  is done by hand.
- **Trash on Google Drive:** a deleted note goes to Drive's own trash, not
  the Mac's; Finder's Put Back does not apply to it.
- **A crash within a second of typing** can lose that second (saving runs
  after a 1 s pause; there is no crash journal).
- **OneDrive reports one change in several steps;** the tree then updates a
  few times in quick succession, and the result is correct.
- **Unexplained once (2026-09-17):** an online-only note on Google Drive left
  its folder after "Move to Trash". The current path refuses this visibly
  (3 of 3 runs); the cause was not found.
- The command line is not frozen until 1.0.0; commands and JSON shapes may
  still change before then.
- Unsigned: see "first launch" below. Apple Silicon only, macOS 14+.

### Für Nutzer der alten Novalis-App / For users of the old Novalis

- Der Branch `legacy` und die Releases bis v0.2.1-rc2 werden nicht mehr gepflegt.
- Vor dem ersten Öffnen eines alten Vaults: `novalis migrate --dry-run`, dann
  die alte App auf allen Geräten beenden, warten bis die Synchronisierung ruht,
  dann `novalis migrate --apply`.
- The `legacy` branch and releases up to v0.2.1-rc2 are unsupported.
- Before opening an old vault: `novalis migrate --dry-run`, quit the old app on
  every device, wait until sync is idle, then `novalis migrate --apply`.
