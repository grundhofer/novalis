## novalis v1.0.0-alpha.1

Die erste Vorabversion der neu geschriebenen App. Alpha heißt: für den
täglichen Gebrauch auf einem eigenen Vault gedacht, aber noch nicht auf allen
Sync-Wegen geprüft — die Liste unten sagt, welche.

The first pre-release of the rewritten app. Alpha means: meant for daily use on
a vault of your own, not yet verified on every sync path — the list below says
which.

### Neu / New

- **Notizen:** Ordnerbaum mit Sortierung nach Name oder Änderung, Tabs,
  Schnellöffnen (`⌘P`), Vault-Suche (`⇧⌘F`), Umbenennen mit Umschreiben der
  Links, Verschieben per Drag & Drop, macOS-Papierkorb, Heutige Notiz
  (`journal/JJJJ-MM-TT.md`), Rückverweise pro Link mit Sprung zur Stelle,
  `[[`-Vervollständigung für Notizen und Überschriften, `#`-Tags.
- **Editor:** CodeMirror 6 mit Sublime-Tastatur (Mehrfachcursor, Zeilen
  bewegen/duplizieren, Gehe zu Zeile), Rechtschreibprüfung von macOS, Bilder
  per `⌘V` oder Ziehen als Anhang neben der Notiz.
- **Lesemodus (`⌘E`):** in Rust gerendert, Mermaid-Diagramme, Suchen und
  `⌘B`/`⌘I` wirken auch dort.
- **Anzeige:** PDF und Bilder öffnen schreibgeschützt im Fenster.
- **Kanban:** Boards als Ordner mit einer JSON-Datei pro Karte, Spalten,
  Kartenbeschreibung, Karten zwischen Boards ziehen, Boards sortieren.
- **Kommandozeile `novalis`:** `ls`, `cat`, `new`, `edit`, `mv`, `rm`,
  `search`, `links`, `tags`, `board`, `card`, `doctor`, `migrate` u. a. — alles mit
  `--json`, Exit-Codes nach Vertrag.
- **Sync-Bewusstsein:** Vault in OneDrive oder Google Drive wird erkannt;
  Nur-Online-Notizen sind markiert, werden beim Öffnen geladen und von der
  Suche übersprungen; jede Speicherung ist atomar; Änderungen von außen werden
  erkannt und nie stillschweigend überschrieben.
- **Privatsphäre:** keine Telemetrie, keine Update-Prüfung, keine
  Netzverbindung. Vier Einstellungen, kein Einstellungsfenster.

- **Notes:** folder tree sorted by name or modification, tabs, quick open
  (`⌘P`), vault search (`⇧⌘F`), rename with link rewriting, move by drag and
  drop, macOS Trash, Today's note (`journal/YYYY-MM-DD.md`), backlinks per
  link with a jump to the line, `[[` completion for notes and headings,
  `#` tags.
- **Editor:** CodeMirror 6 with Sublime keys (multiple cursors, move/duplicate
  lines, go to line), macOS spellcheck, images by `⌘V` or drop as attachments
  beside the note.
- **Preview (`⌘E`):** rendered in Rust, Mermaid diagrams, find and `⌘B`/`⌘I`
  work there too.
- **Viewer:** PDF and images open read-only in the window.
- **Kanban:** boards as folders with one JSON file per card, columns, card
  description, cards dragged between boards, board order.
- **Command line `novalis`:** `ls`, `cat`, `new`, `edit`, `mv`, `rm`,
  `search`, `links`, `tags`, `board`, `card`, `doctor`, `migrate` and more — all with
  `--json`, exit codes by contract.
- **Sync awareness:** a vault in OneDrive or Google Drive is detected;
  online-only notes are marked, downloaded on open and skipped by search; every
  save is atomic; outside changes are detected and never silently overwritten.
- **Privacy:** no telemetry, no update check, no network connection. Four
  settings, no preferences window.

### Bekannt / Known

- **Google Drive legt keine Konfliktkopie an.** Wird dieselbe Notiz auf zwei
  Geräten geändert, behält Drive eine Version und verwirft die andere stumm;
  novalis kann das nicht sehen. Die verworfene Version bleibt im Drive-Verlauf.
  OneDrive: Konfliktkopien werden erkannt und gezählt, aber noch nicht in der
  App aufgelöst (Original/Kopie/beides behalten fehlt).
- **Noch nicht auf OneDrive geprüft** (siehe `docs/FILE-PROVIDER-CHECKLIST.md`):
  Zustellung von Änderungen eines zweiten Geräts, Konfliktkopie-Benennung,
  gleichzeitige Kartenänderung, Papierkorb einer Nur-Online-Notiz, Finder
  „Zurücklegen". Google Drive: Papierkorb einer Nur-Online-Notiz zeigte in
  einem Lauf ein unerklärtes Verhalten (B9).
- **Drive-Web kann `.md` nicht bearbeiten** — es wandelt in ein Google Doc um;
  als zweites Gerät taugt die Drive-App auf dem Telefon.
- Unsigniert: siehe „erster Start" unten. Nur Apple Silicon, macOS 14+.

- **Google Drive makes no conflict copy.** When the same note changes on two
  devices, Drive keeps one version and silently drops the other; novalis cannot
  see that happen. The dropped version stays in Drive's history. OneDrive:
  conflict copies are detected and counted, not yet resolved in the app (keep
  original / copy / both is missing).
- **Not yet verified on OneDrive** (see `docs/FILE-PROVIDER-CHECKLIST.md`):
  delivery of a second device's changes, conflict-copy naming, a concurrent
  card edit, trashing an online-only note, Finder Put Back. Google Drive:
  trashing an online-only note behaved unexplainably in one run (B9).
- **Drive's web UI cannot edit `.md`** — it converts to a Google Doc; the Drive
  phone app works as a second device.
- Unsigned: see "first launch" below. Apple Silicon only, macOS 14+.

### Für Nutzer der alten Novalis-App / For users of the old Novalis

- Der Branch `legacy` und die Releases bis v0.2.1-rc2 werden nicht mehr gepflegt.
- Vor dem ersten Öffnen eines alten Vaults: `novalis migrate --dry-run`, dann
  die alte App auf allen Geräten beenden, warten bis die Synchronisierung ruht,
  dann `novalis migrate --apply`.
- The `legacy` branch and releases up to v0.2.1-rc2 are unsupported.
- Before opening an old vault: `novalis migrate --dry-run`, quit the old app on
  every device, wait until sync is idle, then `novalis migrate --apply`.
