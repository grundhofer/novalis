## novalis v1.0.0-alpha.2

Die zweite Vorabversion. novalis öffnet jetzt weit mehr als Notizen — Code,
Konfiguration, Bücher, Comics, Word-Dokumente — und viele kleine Lücken des
Alltags sind geschlossen.

The second pre-release. novalis now opens far more than notes — code,
configuration, books, comics, Word documents — and many small everyday gaps
are closed.

### Neu / New

- **Dateitypen:** Der Baum listet 93 Endungen und 20 Dateinamen (`Makefile`,
  `Dockerfile`, `LICENSE` …). Code und Konfiguration öffnen in Geist Mono in
  voller Breite, mit Syntaxfarben nach Dateityp, Einrückungslinien, erkannter
  Einrückung und ohne Rechtschreibprüfung. `.markdown`, `.mdx`, `.qmd` u. a.
  öffnen mit Markdown-Grammatik. Eine Datei mit Binärinhalt öffnet
  schreibgeschützt statt kaputt.
- **Schnellöffnen und Suche** über alle gelisteten Dateien (Schalter „Alle
  Dateien"); ein Treffer öffnet an seiner Zeile, mit Pfeiltasten wählbar,
  Treffer markiert, Ordnerfilter; Tags in der Befehlspalette.
- **Lesemodus (`⌘E`):** Codeblöcke farbig nach ihrer Sprache; Überschriften
  anspringen auch dort; `[[notiz#überschrift]]` landet an der Überschrift;
  Bilder öffnen per Klick im Viewer.
- **Viewer:** EPUB und CBZ (Seite für Seite), DOCX (bis 15 MB), HEIC/HEIF/AVIF,
  Bild-Zoom, PDF-Inhaltsverzeichnis und Seitentasten, CSV/TSV als Tabelle und
  SVG als Bild hinter dem Auge-Symbol.
- **Editor:** Zeile/Spalte, Auswahl und Cursor-Anzahl in der Statusleiste;
  Cursor und Scrollposition bleiben über Tabwechsel, `⌘E` und Neuladen;
  CRLF-Dateien bleiben CRLF; die roten Rechtschreib-Unterstreichungen
  erscheinen jetzt; Tippen in sehr großen Dateien bleibt flüssig.
- **Fenster:** kommt an alter Stelle und Größe zurück; der Titel nennt Datei
  und Vault; `⌘Q` und Fenster schließen speichern vorher alle offenen Tabs.
- **Verlässlichkeit:** eine auf der Platte gelöschte Notiz schließt ihren
  Tab oder behält ungespeicherten Text unter einem Hinweis; eine
  Nur-Online-Datei zeigt beim Öffnen „wird geladen" und gibt nach 30 Sekunden
  auf; Konfliktkopien sind im Baum markiert; ein Byte-Order-Mark verdeckt den
  Titel nicht mehr; ein Tab auf eine verschwundene Datei legt den Start nicht
  mehr lahm; ein Vault der alten App sagt, wie er migriert wird.
- **Kanban:** ein Rückverweis auf eine Karte lädt ihr Board; jede verknüpfte
  Notiz öffnet aus ihrem Chip.
- **Kommandozeile:** `novalis sync status`, `novalis skill --path` (die
  Agenten-Anleitung liegt jetzt im Tarball unter `share/novalis/skill`),
  `search --all-files`, `utf8` in `cat`, `vault` in `index --status`.

- **File types:** the tree lists 93 extensions and 20 file names (`Makefile`,
  `Dockerfile`, `LICENSE` …). Code and configuration open in Geist Mono at
  full width, with syntax colours by file type, indentation guides, detected
  indentation and no spellcheck. `.markdown`, `.mdx`, `.qmd` and friends open
  with the Markdown grammar. A file with binary content opens read-only
  instead of garbled.
- **Quick open and search** over every listed file ("All files" toggle); a
  hit opens at its line, results are keyboard-driven and highlighted, with a
  folder filter; tags in the command palette.
- **Preview (`⌘E`):** fenced code coloured by its language; heading jump
  works there too; `[[note#heading]]` lands on the heading; images open in the
  viewer on click.
- **Viewer:** EPUB and CBZ (page by page), DOCX (up to 15 MB), HEIC/HEIF/AVIF,
  image zoom, PDF outline and page keys, CSV/TSV as a table and SVG as a
  picture behind the eye glyph.
- **Editor:** line/column, selection and cursor count in the status bar;
  cursor and scroll survive tab switches, `⌘E` and a reload; CRLF files stay
  CRLF; the red spelling underlines now appear; typing stays smooth in very
  large files.
- **Window:** comes back where it was and as large; the title names the file
  and the vault; `⌘Q` and closing the window save every open tab first.
- **Reliability:** a note deleted on disk closes its tab or keeps unsaved text
  under a banner; an online-only file shows loading on open and gives up
  after 30 seconds; conflict copies are marked in the tree; a byte-order mark
  no longer hides a note's title; a tab whose file is gone no longer stops
  the app from starting; a vault written by the old app says how to migrate
  it.
- **Kanban:** a backlink to a card loads its board; every linked note opens
  from its chip.
- **Command line:** `novalis sync status`, `novalis skill --path` (the agent
  guide now ships in the tarball under `share/novalis/skill`),
  `search --all-files`, `utf8` on `cat`, `vault` on `index --status`.

### Bekannt / Known

- **Google Drive legt keine Konfliktkopie an.** Wird dieselbe Notiz auf zwei
  Geräten geändert, behält Drive eine Version und verwirft die andere stumm;
  novalis kann das nicht sehen. Die verworfene Version bleibt im Drive-Verlauf.
  OneDrive: Konfliktkopien werden im Baum markiert; auflösen (Original/Kopie/
  beides behalten) muss man sie noch von Hand.
- **Noch nicht auf OneDrive geprüft** (siehe `docs/FILE-PROVIDER-CHECKLIST.md`):
  Zustellung von Änderungen eines zweiten Geräts, Konfliktkopie-Benennung,
  gleichzeitige Kartenänderung, Papierkorb einer Nur-Online-Notiz, Finder
  „Zurücklegen". Google Drive: Papierkorb einer Nur-Online-Notiz zeigte in
  einem Lauf ein unerklärtes Verhalten (B9).
- **Nicht auf echter Hardware geprüft:** die 30-Sekunden-Grenze beim Öffnen
  einer Nur-Online-Datei in einem echten Drive-Vault, Zoomen mit der
  Trackpad-Geste, Speichern beim Beenden über das Dock.
- **Drive-Web kann `.md` nicht bearbeiten** — es wandelt in ein Google Doc um;
  als zweites Gerät taugt die Drive-App auf dem Telefon.
- Unsigniert: siehe „erster Start" unten. Nur Apple Silicon, macOS 14+.

- **Google Drive makes no conflict copy.** When the same note changes on two
  devices, Drive keeps one version and silently drops the other; novalis cannot
  see that happen. The dropped version stays in Drive's history. OneDrive:
  conflict copies are marked in the tree; resolving them (keep original /
  copy / both) is still done by hand.
- **Not yet verified on OneDrive** (see `docs/FILE-PROVIDER-CHECKLIST.md`):
  delivery of a second device's changes, conflict-copy naming, a concurrent
  card edit, trashing an online-only note, Finder Put Back. Google Drive:
  trashing an online-only note behaved unexplainably in one run (B9).
- **Not verified on real hardware:** the 30-second limit when opening an
  online-only file in a real Drive vault, zooming with the trackpad pinch,
  saving on quit from the Dock.
- **Drive's web UI cannot edit `.md`** — it converts to a Google Doc; the Drive
  phone app works as a second device.
- Unsigned: see "first launch" below. Apple Silicon only, macOS 14+.

### Für Nutzer der alten Novalis-App / For users of the old Novalis

- Der Branch `legacy` und die Releases bis v0.2.1-rc2 werden nicht mehr gepflegt.
- Vor dem ersten Öffnen eines alten Vaults: `novalis migrate --dry-run`, dann
  die alte App auf allen Geräten beenden, warten bis die Synchronisierung ruht,
  dann `novalis migrate --apply`.
- The `legacy` branch and releases up to v0.2.1-rc2 are unsupported.
- Before opening an old vault: `novalis migrate --dry-run`, quit the old app on
  every device, wait until sync is idle, then `novalis migrate --apply`.
