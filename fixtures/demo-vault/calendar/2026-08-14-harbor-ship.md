# Harbor ship window

Four-hour window to push the Harbor release candidate ([[Harbor Overview]]) to general availability. Lena is the named rollback owner and stays reachable for the full window.

Nothing else is scheduled against this morning on purpose. If the migration is clean by ten we stop early rather than filling the time.

The order of operations is [[Harbor Release Checklist]], top to bottom, no improvising.
Release notes are drafted and only need the final commit hash. Anything that surfaces after the window closes goes to the next cycle unless it loses data.
