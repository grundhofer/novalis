# Spaced Repetition

Forgetting is not a malfunction, it is a filter — memory drops what it has not needed
recently. Spaced repetition works by scheduling a review just before the drop, which is
cheap when it works and useless when the material is bad.

That last part is what most write-ups skip. A prompt is only as good as its phrasing: it must
have exactly one answer, be answerable in a few seconds, and not be guessable from its own
wording. Vague cards feel productive and teach nothing, which is why the practice pairs so
naturally with [[Evergreen Notes]] — a note that already states one clear claim converts into
a prompt almost mechanically.

The honest limit: repetition is for facts and vocabulary, the load-bearing details you want
available without a lookup. It does not create understanding. For that you still need to
write, connect and reread, which is the argument in [[Zettelkasten and PARA]]. The oldest
working version of the practice is [[Notes on: Meditations]].
