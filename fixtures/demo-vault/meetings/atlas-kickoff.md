# Atlas kickoff

**Attendees:** Ana Rivera, Tomas Feld, Priya Raman, Jonah Kessler

Ana opened with the funnel data rather than the roadmap, which set a better tone than the usual kickoff. The headline: users don't abandon Atlas at the account step, they abandon it at the first screen that has nothing in it. That single number reshaped the scope — the Onboarding epic is now about what a new vault contains, not about how many steps it takes to create one.

Jonah pushed for a template gallery. We agreed to park it: a gallery is a decision the user has to make before they've earned any context, which is precisely the problem we're trying to remove.

Scope landed smaller than it started, and everyone said so out loud.
